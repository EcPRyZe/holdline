# Holdline

Free ballistic calculator. Point-mass G1/G7 solver, a library of common rifles and published loads, commercial optic sight pictures, and a printable zero target you can photograph to get a click correction.

Reticles are functional drawings from manufacturer manuals (EOTech EXPS3, Primary Arms ACSS Nova, Trijicon TA31 RCO, Vortex AR-BDC3, and others). Where a maker does not publish a subtension, the caption under the glass says the number is derived.

## Run

```bash
npm install
npm run dev
```

Open the app at `http://localhost:8080`.

Rifle, load, and optic choices stay in the browser. There is no account.
